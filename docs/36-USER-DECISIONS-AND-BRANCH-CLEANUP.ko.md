# 사용자 결정 확정과 구형 브랜치 정리

2026-11-18 UTC. 기준 main `2c1a7b3`. [35 결정 검토 보고](35-PENDING-DECISIONS.ko.md)에 대한 사용자의 후속 지시를 기록한다.

> 브랜치 정리. AI 처리 결과는 일차적으로 메타데이터에 표시 및 앱 내 공지. 공유본은 위치 제거, 내보내기한 원본 사진은 위치 포함. 출력 형식은 가능하면 품질 우선.

**이 문서의 제품 정책 확정과 앱 구현 완료는 구분한다.** 이번 작업은 원격 브랜치 정리를 실행하고 개발 기준/일지를 갱신했다. 앱의 AI 표기·위치 수집/공유·출력 코덱 경로는 수정하지 않았다.

## 1. 확정한 제품 정책

| 항목 | 확정 내용 | 구현 시 지킬 경계 |
|---|---|---|
| AI 처리 결과 | 1차로 **메타데이터 표기 + 앱 내 공지** | 앱이 실제 적용한 AI 처리 종류를 구분해 기록하고 기능 설명/결과 정보에서 안내. 단순 구도 분석·일반 LUT·SDR 융합까지 일괄 AI 생성 사진으로 표시하지 않음 |
| 공유본 | **위치 정보 제거** | 별도 공유 사본에서 GPS 및 관련 위치 메타데이터를 제거. 공유를 위해 보관 원본을 수정하지 않음 |
| 원본 사진 내보내기 | **위치 정보 포함/보존** | 권한 허용·유효 위치가 있는 촬영 시점에 태깅하고, 만들어진 원본은 bytes 그대로 내보냄. 원본에 없던 위치를 나중에 주입하거나 재인코딩하지 않음 |
| 출력 형식 | **가능하면 품질 우선** | 파일 크기/속도보다 해상도·색·압축 품질을 우선. JPEG를 무조건 기본으로 고정한다는 기존 제안은 채택하지 않음. 실제 지원/품질 비교 후 형식 결정 |
| 구형 원격 브랜치 | **정리 실행** | main에 미병합인 커밋도 원격 archive 태그로 먼저 보존하고, 지정된3개 브랜치만 삭제 |

### AI 표기

- 앱이 적용한 AI 추정 심도/보정과 향후 초해상 등 실제 처리 종류를 나타내는 메타데이터와 앱 내 안내를 우선한다. 생성형 처리와 분석 기능을 혼동하지 않는다.
- 기존 원본에 AI 표기를 덧붙이지 않는다. 앱이 만든 AI 처리 결과/파생물에 해당 처리 이력을 기록한다.
- 1차 범위는 메타데이터와 앱 내 공지다. 사진 픽셀 워터마크나 C2PA를 추가하지 않는다. C2PA 미도입 결정은 유지한다.
- 구체적인 메타데이터 필드·지원 포맷·문구는 처리 경로에 맞춰 설계/검증한다. 모든 파일 형식에 같은 임의 태그가 보존된다고 가정하지 않는다.

### 위치 정보와 작업 구분

| 사용 동작 | 위치 처리 | 원본 불변 조건 |
|---|---|---|
| 촬영/앱 원본 보관 | 기존 기본 활성화 결정 유지. 허용된 유효 위치를 생성 시점에 기록 | 사진/DNG/영상/Photos 각 API의 지원 계약부터 확인 |
| 원본 사진 내보내기 | 원본에 기록된 위치 포함 | 파일 bytes·hash 유지. 원본이 처음부터 위치가 없으면 없는 상태로 내보내며 만들어내지 않음 |
| 공유 | 위치가 제거된 별도 사본 사용 | 원본·보관용 위치는 그대로 유지. 기존 ShareLink가 원본 URL을 바로 전달하는 경로와 분리 필요 |

권한 거부/설정 끄기·유효 위치 없음이면 위치 없이 촬영한다는 기존 계약은 유지한다. 위치 포함 지시를 이유로 권한을 우회하거나 촬영 후 원본을 수정하지 않는다. 이번 원본 위치 포함 결정이 모든 일반 파생 내보내기에 위치를 추가하라는 지시는 아니다. 공유 경로는 결과 종류와 무관하게 위치 제거 대상이다.

### 품질 우선 출력

- 원본 내보내기는 재압축·자동 축소 없이 원본을 보존한다.
- 파생 출력은 현재 처리 경로가 지원하는 해상도·색 정보를 유지하는 방향으로 설계한다. 위치 제거 공유본도 불필요한 재인코딩/축소를 피하고, 지원하지 않으면 별도의 고품질 사본 경로를 검증한다.
- JPEG·SDR HEIC 등의 품질·메타데이터 지원·호환성·메모리/저장 비용을 비교해 적합한 형식을 정한다. HEIC라는 이유만으로 항상 고품질이라고 보증하지 않는다.
- 최고 압축 품질 설정과 무손실은 다르다. JPEG/HEIC의 품질 값을1.0으로 설정했다는 이유만으로 무손실이라고 표시하지 않는다.
- HDR/게인맵·Log 영상·C2PA 미도입과 SDR/sRGB 계약은 그대로다. 실제 출력 색공간과 맞지 않는 원본 ICC를 무조건 복사하지 않는다.
- 품질 우선은 지원 한도를 임의로 늘리는 변경이 아니다. 기존 LUT/심도64MP 경로와 F1 융합12.6MP 상한은 실제 추가 구현/검증 전 유지한다.
