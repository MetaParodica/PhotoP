## 4. 실패와 대응

### 기존 개발에서 확인한 실패/해결 — 회고

### 이번 문서 작업에서의 확인

- Cloud 재개 직후 실행 도구가 아직 연결되지 않아 첫 저장소 조회가 실패했다. 환경 ready/connected를 확인하고 재조회했다. 저장소 변경은 없었다.
