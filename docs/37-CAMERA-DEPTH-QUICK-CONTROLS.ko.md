## 2. 공식 SONY·CANON 문서에서 적용한 원칙

공식 원문8개를 직접 조회해 HTTP200·조회 시각·SHA-256을 [출처 기록](research/2026-11-18-camera-ui-sources.json)에 저장했다. UI 이미지·외부 코드를 복사하지 않았다.

- [Sony α7 IV Fn](https://helpguide.sony.net/ilc/2110/v1/en/contents/TP1000616725.html): 자주 쓰는 기능을 촬영 화면에서 빠르게 호출하고 값을 조절한다. PhotoP에서는 PRO 첫 f값과 즉시 적용 버튼에 반영했다.
- [Sony Touch Focus](https://helpguide.sony.net/ilc/2110/v1/en/contents/TP1000649045.html), [AF-ON](https://helpguide.sony.net/ilc/2110/v1/en/contents/TP1000657960.html): 피사체 위치를 직접 지정하고 셔터와 초점 재설정을 분리한다. 기존 화면 터치/길게 누르기와 AF-ON을 간편 패널에서 접근하게 했다. Sony의 실제 반셔터 동작을 그대로 구현했다는 뜻은 아니다.
- [Canon R5 Mark II Quick Control](https://cam.start.canon/en/C017/manual/html/UG-01_Preparations_0140.html): 항목 선택 뒤 직접 값을 설정한다. 복잡한 입력 소스 선택보다 촬영에 필요한 값부터 노출한다.
- [Canon Av](https://cam.start.canon/en/C017/manual/html/UG-02_ShootingMode_0070.html): 낮은 f값과 얕은 심도의 관계를 안내한다. PhotoP는 전경·배경 흐림과 초점 위치 안내로 옮겼으며 실제 광학 조리개/자동 셔터 연동을 주장하지 않는다.
- [Canon AF 영역](https://cam.start.canon/en/C017/manual/html/UG-04_AF-Drive_0060.html): 영역 선택과 초점 대상을 분리한다. 기존 AF-C/AF-S·AF/AE·MF 설정은 초점 패널에 유지한다.

## 3. 전경 아웃포커스 처리 변경

기존 경로는 깊이2~98백분위로 맵을 자르고 일정 깊이 간격의 층과 고정 정규화 초점 보호 폭을 사용했다. 작은 근거리 물체의 깊이 차이가 사라지거나, 실제로 흐려야 할 부분이 초점 보호 영역에 포함될 수 있었다.

1. 깊이 대비가 백분위에서 사라져도 최소3개의 유효 샘플이 지지하는 작은 전경은 범위를 유지한다. 고립된1개 스파이크·균일 깊이는 계속 거부한다.
2. 유효 깊이마다 실제 사용 중인 절대/상대 CoC 식을 먼저 적용하고 Float32 수치 맵으로 전달한다. 무효 깊이를 무한대로 취급하지 않는다.
3. 초점 주변에 촘촘한 CoC 층을 배치한다. 일반17층/저예산9층으로 기존 합성 예산 범위 안에 둔다. 반경 상한48px/4032px와64MP 지원 한도를 늘리지 않는다.
4. 원본 초점면 복원은 장면 전체 깊이 범위가 아닌 출력 기준 반경0.5~1.5px/4032px로 전이한다.
5. 가까운 층의 삼각 가중치를 coverage로 합산한 뒤 alpha를 제한한다. 초점면을 복원한 다음 전경을 합성해 흐림이 뒤의 선명한 부분까지 퍼지는 동작을 유지한다.

가려진 배경의 실제 디테일·경쟁 앱 수준 화질을 복원했다고 주장하지 않는다. AI 상대 깊이의 거리 오차, 머리카락/반사체/작은 물체와 센서 유효 범위는 여전히 제한이다. 실제 중·원거리 장면/48MP 비용 비교는 남았다.

## 4. 무음 촬영의 실제 범위

[Apple 지원 여부](https://developer.apple.com/documentation/avfoundation/avcapturephotooutput/isshuttersoundsuppressionsupported) 문서는 셔터음을 끌 수 없는 관할에서는 지원값이 false라고 명시한다. [촬영별 요청](https://developer.apple.com/documentation/avfoundation/avcapturephotosettings/isshuttersoundsuppressionenabled)은 기본 false이며 지원하지 않을 때 true로 촬영하면 예외가 발생한다.

현재 `CameraService`는 일반/RAW/브래킷 설정이 합쳐지는 공통 경로에서 **지원값을 확인한 뒤 매 촬영 요청에 true**를 적용한다. 이 부분은 이전부터 구현된 동작이고 이번 변경은 안내 문구/접근성 식별자 정리다. 비공개 음소거·저해상도 영상 프레임 대체는 추가하지 않았다. 실제 기기 소리 확인은 미수행이다.
