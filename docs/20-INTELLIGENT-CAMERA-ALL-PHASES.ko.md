## 사용 흐름

1. 카메라 하단 **AI**로 켜기/끄기. 길게 누르면 **구도 라이브러리**, **촬영 의도·코치 설정**을 연다.
2. 구도 패널에서 의도·자동/수동 구도·목표 좌우·인물 선택을 즉시 조정한다. 후보 세 개에는 근거를 표시하며 사진 점수/확률을 표시하지 않는다.
3. 라이브러리는 자체 제작 도식·설명·분류를 제공한다. 선택 즉시 기존 프리셋/포즈 중복을 지우고 해당 AI 구도를 적용한다. 인식이 없거나 지원되지 않아도 선택한 수동 도식은 사용할 수 있다.
4. 노란 박스=선택 인물, 청록=다른 인물/측정 직선·수평 방향, 흰 점선=구도 기준, 초록=안정된 정렬. 기기 이동 방향을 알 수 없으면 **화면 속 대상**과 목표점 방향만 안내한다.
5. 코치의 **배율/렌즈 제안**은 탭할 때만 적용된다. **노출 설정**은 하단의 기존 EV 또는 수동 셔터 패널만 연다. ISO·셔터·EV·AF·AE 잠금을 임의 변경하지 않는다.
6. 촬영 후 자동 리뷰를 켜면 원본 보존·결과 처리·사진 앱 저장 시도 뒤 리뷰한다. 최근 촬영 화면의 **AI 촬영 리뷰**에서 확인/수동 분석한다. 원본과 별도 효과 결과를 각각 선택할 수 있다.

## 자동 분석의 근거와 한계

- 인물/얼굴: Vision 사람/얼굴 사각형과 실제 얼굴 중심. 눈높이·시선·생체 식별은 아니다. 다중 인물 추적은 공간 대응이므로 교차/가림 후 동일성은 보장하지 않는다.
- 관심 영역: Vision attention saliency. 동물·음식·제품·차량 등 사물 종류로 바꾸지 않는다. 추가 객체 분류 모델은 도입하지 않았다.
- 사각형/직선: Vision 사각형과 96×96 SDR 경계의 제한된 Hough 직선(최대 900경계/36방향/6선). 건축물 의미 분류, 3D 소실점·거리·촬영 높이 복원은 아니다. 반복 추천은 유사 방향 직선이 세 개 이상일 때만 허용하며 등간격/사물 반복을 보장하지 않는다.
- 수평: Vision의 추정 방향을 상단 원점 각도로 변환한다. 화면 중앙을 지나는 방향 표시이며 실제 지평선 높이·하늘 분할은 아니다. 기기 롤·앞뒤 피치와 사각형의 좌우 수직선 차이를 별도로 설명한다.
- 구도 29항목은 자동을 포함한다. 황금나선·원형·상하 대칭·전경/중경/원경·거리·제품/음식·천체는 수동 도식으로 명시한다. 별 추적·음식 인식·깊이 레이어 자동 검출을 가장하지 않는다. 자동 후보는 실제 인물 수/크기, 관심 영역, 선/사각형/수평, 이미지 비율, 촬영 모드와 의도에 근거한다. 근거가 없으면 불확실함을 밝히고 중앙 수동 기준을 제공한다.
- 줌: 실제 장치 최대값 및 앱 디지털 상한 5×, 현재 렌즈의 화각 배율만 사용한다. 다른 물리 카메라는 실제 목록에 있는 경우만 제안한다. RAW에는 제안하지 않고, 영상은 현재 카메라 디지털 줌만 허용한다. 심도 활성 상태에서 타 렌즈를 제안하지 않는다. 수동 줌/렌즈 조작 뒤 8초간 줌 제안을 쉬고, 버튼은 결과 나이·렌즈·현재 배율이 일치할 때만 동작한다.
- 노출: encoded sRGB SDR 평균 휘도·밝은 채널 상한 근접·저휘도 및 실제 얼굴/대상 영역 평균을 사용한다. RAW 센서 클리핑/lux/HDR 손실 측정이 아니다. 수동/AE 잠금이면 노출 조언은 유지하되 자동 변경하지 않는다고 표시한다.
- 정렬: 기존 0.6초 유지/히스테리시스/3초 햅틱 제한을 재사용한다. 자동 구도 전환은 0.8초 후보 유지, 코치 메시지는 0.6초 조건 유지가 필요하다. 사라진 경고와 오래된 조작 payload는 즉시 제외한다.

## 촬영 후 리뷰·선호 기록

- 원본 SHA-256과 방향이 적용된 최대 640px SDR 이미지를 사용한다. 표준 96px 표본의 평균/경계 대비·좌우/상하 밝기차·RGB 평균과 Vision 결과를 분석한다. 경계 대비는 질감/조명/축소에도 영향을 받으며 원본 초점이나 흔들림 확정 판정이 아니다.
- 결과별 **측정 / 조언 / 제한**을 표시하고 임의 90점/95점 같은 미학 점수를 만들지 않는다. 원본 bytes/EXIF와 사진 앱의 자산은 변경하지 않는다.
- RAW는 ImageIO의 **내장 SDR 썸네일만** 허용한다. 없으면 리뷰를 생략하고 이유를 표시한다. RAW 현상이나 센서 평가로 표시하지 않는다.
- 촬영 직전의 목표/대상 위치를 보관하고 저장 이미지와 비율·인물 수·공간 겹침·얼굴 랜드마크 유무가 충분히 일치할 때만 전후 목표점 거리를 비교한다. 공간 대응이지 동일 인물 확인/미학 점수가 아니다. 조건 불일치 시 비교를 생략한다. 전면 프리뷰의 미러링은 원본 좌표로 되돌린다.
- 리뷰는 `Documents/CoachReviews/<SHA256>.json`에 버전·파일명·해시·측정/설명·선택적 촬영 전 참조를 원자 저장한다. 읽기는 512KiB 제한, 버전/해시/필드/좌표를 검증한다. 캐시는 256개까지 저장하며 이후 새 리뷰는 메모리에만 제공한다(기존 사진/리뷰를 자동 삭제하지 않는다). 메모리 보고서·오류는 각 8개로 제한한다.
- 선택적 학습은 기본 꺼짐. 켜면 **직접 선택하여 촬영한 의도:구도 횟수**만 UserDefaults에 저장한다. 항목 최대 1000회, 후보 가산 최대 5, 스키마/64KiB 상한을 검증한다. 자동 선택·사진·얼굴·외형·위치는 학습하지 않는다. 끄거나 초기화하면 구도 횟수를 제거한다. 신경망 재훈련이나 성공 사진 판단은 아니다. 리뷰 JSON의 별도 보관과 구분한다.

## 처리 예산·기존 모드 보호

- 기존 BGRA 출력·네이티브 프리뷰·Metal 모니터를 재사용한다. 별도 카메라 세션/분석 출력을 추가하지 않는다. LUT 카메라/카드 미리보기는 이전 요청대로 끈 상태다.
- 분석은 최대 640px·인물 최대 5Hz·한 작업. 기하/관심 영역/Hough는 약 0.8초 간격, 저전력/심각 발열 및 영상 녹화 시 인물 상한 2.5Hz, 임계 발열이면 새 분석 중지. 이는 설정 상한이지 측정 성능 수치가 아니다.
- 인물/가이드/조작 제안은 650ms 만료, 기하 증거는 1.2초 만료, 모션은 1초 만료다. 회전/렌즈/줌/세션 세대가 바뀌면 오래된 콜백을 거부한다. 실제 viewport와 프레이밍 가이드의 교집합에 목표를 둔다.
- 리뷰와 라이브 Vision에는 하나의 공유 추론 게이트가 있다. 리뷰 중 라이브 추론만 잠시 중지하고 네이티브 프리뷰·Metal 노출 보조·수동 제어는 유지한다. 이미 진행 중인 Vision 요청이 있으면 리뷰는 종료를 기다린다. 새 사진/영상·백그라운드 전환 시 리뷰를 취소하고 작업 ID로 늦은 결과를 거부한다. 시스템 Vision 호출 자체는 중간 취소되지 않을 수 있으나 대기 프레임을 쌓지 않는다.
- 사진 촬영 동안 라이브 추론을 중지하고 토글로 재활성화되지 않도록 보호한다. RAW/브래킷 셔터 시 분석 출력을 직렬 큐에서 해제하되 서비스의 실제 호환성 검사는 유지한다. 완료/실패 뒤 사용자 분석 설정을 복구한다.
- LONG은 합성 전에 분석 출력을 해제하고 끝난 뒤 복구한다. 자동 리뷰는 완성된 합성 원본만 대상으로 한다. 취소/실패로 과거 결과를 새로 리뷰하지 않는다.
- VIDEO는 기존 MovieFileOutput+VideoDataOutput 동시 구성을 장치가 허용할 때만 분석한다. 미지원 시 저장/녹화를 우선하고 상태 안내·수동 도식으로 남긴다. 코치/구도 오버레이를 사진/영상에 굽지 않는다. Apple Log/HDR·LUT 영상 굽기를 추가한 것이 아니다.

## 추가 인수·개선 우선순위

1. Mac SDK 전체 빌드/strict concurrency 진단 및 통합·UI 테스트 실행. 실제 앱 UI 켜짐/꺼짐·라이브러리·코치·리뷰 화면 캡처.
2. 실제 단일/복수 인물·교차/가림·빠른 움직임에서 검출/대상 유지/정렬 지연 및 오검출 측정. 전후면·가로세로·fit/fill·줌·프레이밍마다 좌표 확인.
3. 지원 물리 렌즈 전환, RAW·브래킷 분석 해제 후 촬영과 원본/EXIF/Photos 저장, PRO 수동·잠금 유지, LONG 취소/재처리, 4K/60fps 영상 동시 출력과 인코딩 안정성 확인.
4. Core Motion 부호/회전, 수평 방향 표시, 실제 역광/저조도/색조명에서 경고 임계값을 촬영 데이터로 보정. 현재 임계값은 설명 가능한 초기 휴리스틱이지 보편적 촬영 품질 기준이 아니다.
5. Instruments로 추론 p50/p95·원본 프리뷰 FPS·영상 드롭·메모리·발열·배터리 측정 후 기기별 상한 조정. 필요하면 상세 분석 주기를 더 낮춘다. 구현 예산만으로 무저하를 보장하지 않는다.
6. 현재 수동인 구도 자동화·동물/음식 등 의미 분류·실제 깊이 레이어·개인별 미학 모델은 별도 검증/라이선스가 필요한 확장이다. 모델 없는 상태에서 자동 인식 완료로 표시하지 않는다.
