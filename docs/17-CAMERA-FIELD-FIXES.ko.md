## 조사에서 추가로 발견하여 수정한 문제

- 초점이나 WB를 바꿀 때 노출 등 모든 제어까지 재적용하던 경로를 수정했다. 변경된 제어만 적용하고 중복 요청은 생략한다.
- 수동 제어 진입 시 임의 초기값으로 튀지 않도록 실제 readout을 사용한다. 수동 EV 메뉴에 셔터 슬라이더를 잘못 표시하던 문제도 수정했다.
- 녹화 전체를 `busy`로 표시하던 상태를 분리했다. 녹화 중 ISO·셔터·WB·초점·분석은 조절할 수 있다. 해상도/FPS/코덱/오디오/보정 구성은 녹화 중 유지한다.
- 설정 timeout 중 녹화가 진행 중이면 녹화 종료·파일 완료 timeout도 함께 적용한다.
- 룩 연속 선택 시 오래된 로드가 최신 선택을 덮지 않도록 직렬화했다. 렌즈 전환 시 룩을 잠시 중지하고 전환 완료 후 복원한다.
- 가로 프레이밍 비율 및 영상 fill/fit에서 가이드와 분석 화면의 좌표를 맞췄다.

## 깊이 패키지

`Documents/DepthCaptures/<UUID>/Capture.photopdepth`와 `Photo.jpg`를 별도로 원자적으로 저장하고 각각 공유한다. JPEG에 깊이를 삽입한 HEIF/인물사진 파일은 아니다.

패키지는 `PHOTOPDEPTH1\n` ASCII → JSON 길이(UInt32 little-endian) → UTF-8 JSON → depth → confidence → JPEG 순서다. JSON에 각 데이터 길이·SHA-256·치수·intrinsics 9개·camera transform 16개·timestamp를 기록한다. 깊이는 행 패딩을 제거한 Float32 little-endian 미터 값, 신뢰도는 픽셀당 UInt8(0/1/2)이다. RGB와 깊이는 native 카메라 좌표로 저장한다. 두 해상도 비율로 intrinsics를 스케일해야 하며 NaN/0 깊이는 유효 거리로 해석하지 않는다. 행렬은 column-major이다.
