# 사진·영상 공통 심도 개발 계획

사용자 요청 기준일: 2026-11-19, Asia/Seoul. 기준 main `37eb109`. [39 공식/오픈소스 조사](39-VIDEO-DEPTH-AND-TRACKING-RESEARCH.ko.md)를 먼저 작성하고 다음 단계로 구현한다. 사용자가 지정한 **조사→계획→개발→오류 수정→테스트→main push** 순서를 따른다.

## 1. 범위와 제품 계약

- 사진의 심도를 영상 프리뷰와 저장 결과까지 확장한다. AI 구도 추천/코치/자동 리뷰는 계속 중지한다.
- 화면에서 선택한 피사체를 사진/영상 공통 추적 대상으로 사용한다. 대상 지정·추적 중·불확실·놓침을 구분하고 오래된 결과/렌즈·방향 변경의 이전 상태를 버린다.
- 영상은 **원본 MOV를 변경하지 않고 별도 심도 MOV + 레시피**를 만든다. 프리뷰 적용을 저장 결과 적용으로 가장하지 않는다. 실제 적용된 AI 처리는 앱 안내와 지원되는 영상 메타데이터에 기록한다.
- 원본의 프레임 크기·PTS/오디오를 보존하는 SDR 출력이 기본이다. 처리에 시간이 걸릴 수 있으며 진행·취소·실패/원본 복귀를 표시한다. 자동 해상도 축소로 품질 문제를 숨기지 않는다.
- 새 대형 모델이나 서버 전송을 이번 기본 경로에 추가하지 않는다. 기존 고정 Core ML Depth Anything V2 Small·선택 매트·NaturalDepthEngine을 재사용한다.

## 3. 구현 구조

- `SubjectTrackingPolicy`: 정규화 top-left 이미지 좌표, 대상 UUID·generation·단조 시간·bbox, 안정/약한 관측/놓침 상태. ByteTrack의 score fusion을 스칼라로 포트하며 초기 seed와 관측의 연관을 검증한다. 사진/영상·편집기에서 재사용한다.
- `SubjectTrackingAnalyzer`: 한 번에1개 분석, 최신 프레임만 처리. Vision 시퀀스로 사용자 지정 물체를 추적하고 인물/얼굴 모드는 처음 선택에 검출 결과를 사용한다. AI 추천은 켜지 않는다.
- `LiveLUTPreview`/`LiveDepthAnalyzer`: 캡처/render 큐를 무거운 추론으로 막지 않는다. 추적 결과의 신선도와 세대를 확인하고 현재 대상만 심도 초점으로 사용한다. 열/백그라운드/렌즈 변경 시 초기화한다.
- `VideoDepthPolicy`: 품질/유효 입력, 초점·f값·프로필 시간 설정, 변경량/크기/시간/상태의 검증. 과도한 이벤트/프레임 캐시 제한.
- `VideoDepthProcessor`: 원본 hash/SDR·트랙 검증 후 프레임을 순서대로 처리하고 같은 PTS로 기록한다. 프리뷰 축소와 출력 해상도를 혼동하지 않는다. 가능한 한 프레임/풀을 재사용하고 작업 수를 제한한다. 오디오를 유지하고 완료 전 결과를 성공으로 노출하지 않는다.
- `VideoDepthStore`: 새 UUID의 pending 폴더→완성 MOV/recipe 검증→원자 publish. 원본 폴더/파일을 변경하지 않는다. 취소 시 자신이 만든 pending만 제거한다.
- UI: VIDEO에도 심도 f값/대상 추적. 원본 녹화와 심도 파생 결과를 명확히 구분. 영상 보관함에서 심도 편집/원본 비교/결과 재생·저장·취소 제공.

## 4. 안전한 추적·심도 정책

- 관측 confidence, IoU/이동/면적 변화, 타임스탬프·generation을 함께 검사한다. 얼굴/박스를 신원 인식이라고 표시하지 않는다.
- 약한 관측·놓침은 새 대상 확정이 아니다. 불확실한 대상의 낡은 마스크를 계속 표시하지 않고 원본 프리뷰/프레임으로 복귀하며 상태를 알린다.
- 상대 깊이에 m 단위 입력/표시를 만들지 않는다. 단일 이미지 깊이를 단순 평균하면 척도/장면 컷 때문에 번질 수 있으므로 정합이 검증되지 않으면 매 프레임 신선한 추정을 사용한다.
- 선택 매트·전경 spill·초점 보호·원본 비교·색/타일 계약은 사진 엔진과 공유한다. 가려진 배경을 실제로 복원했다고 주장하지 않는다.
- 녹화 중 수정은 가능한 소프트웨어 프리뷰/파생 설정에 적용한다. 네이티브 Cinematic의 `simulatedAperture`를 녹화 중 변경하지 않는다.
