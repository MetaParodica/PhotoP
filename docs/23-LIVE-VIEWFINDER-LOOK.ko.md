# 뷰파인더에 선택 룩 실시간 적용

2026-10-23 KST. 기준 main `c470430`. 사용자가 LUT가 적용된 상태를 뷰파인더에 보여 달라고 요청하여 이전 “촬영 결과 전용·카메라 프리뷰 무보정” 정책을 변경했다. 카드별 예시 썸네일 렌더링은 다시 켜지 않았다. 후속 게시 요청에 따라 `codex/live-viewfinder-lut` 브랜치에 커밋·푸시한 뒤 main에 fast-forward 병합하는 절차를 따른다. 최종 반영 hash와 원격 반영 여부는 대화의 Git 확인 결과를 참조한다.

## 동작

- 룩/사용자 LUT/즐겨찾기/프리셋을 선택하면, 카메라가 연결된 상태에서 실제 선택 LUT로 SDR Metal 프리뷰를 만든다. AI·노출 보조가 모두 꺼져 있어도 선택 룩만으로 프리뷰가 필요하다고 판단한다. 카메라가 없으면 선택만 보관하며 가짜 영상이나 적용 완료 상태를 표시하지 않는다.
- 강도·그레인 양/seed·필름 마감은 다음 프리뷰 프레임에 반영한다. LUT 강도가0이어도 별도 입자·공간 효과는 유지한다.
- **원본 프리뷰와 비교**는 표시의 LUT·입자·마감을 모두 우회한다. 선택한 룩/설정이나 촬영 후 결과에 적용할 값은 바꾸지 않는다. 비교를 끄면 원래 룩이 돌아온다.
- **룩 적용 해제**는 무보정 화면으로 돌아간다. AI·히스토그램·초점 보조 등이 필요하면 같은 프리뷰 출력을 중립 상태로 유지하고, 다른 수요가 없으면 출력을 해제한다.
- **AI·노출 보조 끄기**는 분석 도구만 끄며 선택한 뷰파인더 룩은 유지한다. 선택 룩까지 해제하는 동작과 구분한다.
- 상태 문구를 연결 대기/실제 프레임 준비/원본 비교로 나눈다. 강도0·항등에 가까운 색상표·공간 효과 중심 룩 안내도 유지한다.

## 처리·수동 제어 보호

- 최초 연결은 기존 `CameraService.setLivePreview`의 sRGB SDR/BGRA 출력을 재사용한다. 새 카메라 세션/중복 VideoDataOutput을 만들지 않는다. 현재 색 프로파일 검증과 오류 처리는 유지한다.
- 이미 연결된 상태에서 LUT를 바꾸면 AVFoundation 출력/장치 설정을 재구성하지 않는다. `LiveLUTPreview`에 최신 LUT 요청 하나만 보관하고 frameQueue에서 새 processor를 준비한다. ISO·셔터·EV·AF·AE/WB 잠금 설정을 변경하지 않는다.
- 요청 세대가 일치한 processor만 설치하고, 최신 설치가 준비되지 않은 동안 과거 LUT를 새 선택의 ready 상태로 인정하지 않는다. `PreviewFrameState`의 한 GPU 프레임 제한은 그대로다.
- 완료 콜백은 작업을 인코딩한 정확한 processor를 보유한다. LUT 교체 시 이전 GPU 작업의 텍스처/히스토그램을 새 processor와 혼용하지 않는다. 이미 제출한 GPU 작업 자체를 강제로 취소하지는 않는다.
- AI/saliency/히스토그램·zebra·peaking 측정은 **LUT 이전 입력**을 계속 사용한다. 화면에는 선택 룩과 필요 시 보조 표시를 겹친다. 룩이 노출 측정값을 왜곡하도록 경로를 바꾸지 않았다.
- 기존 저전력/발열 예산(프리뷰 최대1024/720/480px, 처리 빈도 상한)과 오래된 프레임 거부를 유지한다. 첫 선택/표 교체의 준비 비용과 실제 FPS·메모리·색 일치는 실기기에서 측정해야 한다.

## 촬영 결과와의 구분

- 일반 사진은 기존64MP 파일 기반 경로로 별도 LUT/필름 결과를 생성한다. 원본 bytes/EXIF는 계속 보존한다. 프리뷰에만 굽고 저장 결과는 빠지는 방식으로 변경하지 않았다.
- f값 심도 효과의 실시간 합성을 추가한 것은 아니다. 실제 사진 깊이 기반 흐림은 촬영 후 결과에만 적용한다. 프리뷰와 고해상도 결과의 축소/공간 샘플 차이는 남아 있다.
- RAW/브래킷 촬영은 기존대로 셔터 시 분석 출력을 해제한 뒤 촬영하고 선택 프리뷰를 복구한다. 저장 DNG는 무보정이며 뷰파인더의 SDR 룩은 모니터링이다.
- LONG 합성 중에는 실시간 출력/분석을 해제하고 끝난 뒤 복구한다. 합성 결과에도 선택 룩의 별도 결과를 만든다.
- VIDEO는 사진 모드에서 선택한 룩을 보관하며 장치가 movie/data 동시 출력을 허용할 때만 뷰파인더에 표시한다. 룩 선택 UI는 사진 모드에서 조작한다. 저장 영상은 기존 SDR 무보정이며 LUT 영상 굽기/Log/HDR을 추가하지 않았다. 미지원 구성에는 오류/수동 프리뷰로 남긴다.
