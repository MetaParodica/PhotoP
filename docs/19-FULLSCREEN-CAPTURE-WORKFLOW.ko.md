# 전체 화면·촬영 룩·PRO 심도·장노출 시간 변경

2026-10-22. `bddf682` 이후 로컬 AI Phase 1 변경을 보존하고 추가했다. 아직 커밋/푸시하지 않았다. 이번 사용자 요청은 이전의 “뷰파인더와 하단 패널 분리” 및 “실시간 LUT/장면 썸네일” 요구를 대체한다.

## 1. 설정 뒤까지 이어지는 뷰파인더

- `CameraView`의 세로 분할 레이아웃을 전체 이미지 배경 + 상단/하단 제어 오버레이로 변경했다. 설정/카드를 열어도 이미지 영역을 줄이지 않는다.
- 영상은 기존 전체 프레임/화면 채움 선택을 유지한다. 사진은 화면을 채우며, **프리뷰에서 가장자리가 잘릴 수 있지만 원본 전체 프레임은 그대로 저장**한다.
- 안전 영역은 영상 배경만 확장하고, 실제 조작 버튼은 노치·홈 인디케이터 안쪽에 둔다. 하단은 반투명 재질/그라데이션으로 읽기 쉽게 한다. 숫자 입력 시 키보드 회피를 유지한다.
- 네이티브/중립 Metal 프리뷰와 구도/인물/프레이밍 오버레이에 같은 fit/fill 정책을 사용한다. 탭 좌표는 기존 AVFoundation 공식 변환을 재사용한다.
- AI 안내 문구는 하단 패널 위로 옮겼다. 구도 목표의 기준은 여전히 원본 이미지 전체이며, 화면 채움으로 잘린 부분이나 수동 1:1/16:9 마스크를 별도 목표 영역으로 재해석하지 않는다.

## 2. LUT 미리보기 제거 및 촬영 결과 적용

“미리보기 없이”를 **카메라/예시 프리뷰는 사용하지 않고 선택한 룩은 촬영 결과에만 적용**하는 것으로 해석했다. 선택 룩 자체를 삭제하거나 편집기 기능을 삭제한 것은 아니다.

- 카메라 LUT/공간 효과 프리뷰, 원본 비교 토글, 실제 장면 예시 렌더링을 촬영 UI에서 제거했다. 카드/목록은 이름·설명·기호로 선택한다.
- 룩을 선택할 때 카메라 연결, Metal 프리뷰 시작/교체 또는 AI/노출 보조 초기화를 하지 않는다. 모니터링/AI/수동 초점 보조는 필요할 때 **중립 영상**만 사용한다. 장면 썸네일 샘플도 요청하지 않는다.
- `CameraModel`의 일부 `live*` 내부 속성/함수 이름은 기존 호출 호환을 위해 유지하지만, LUT 관련 값은 이제 선택된 **촬영 후 룩**을 뜻한다. 프리뷰 강도는 항상 0이며 중립 마감만 사용한다.
- 촬영 시 선택 룩/강도/마감을 값으로 확정한다. 원본을 먼저 저장한 뒤 `CaptureResultProcessor`가 별도 SDR JPEG를 만든다. 사진 브래킷은 프레임별로 처리하며 장노출 합성 결과에도 선택 룩을 적용한다. RAW/DNG·영상에는 룩을 굽지 않는다.
- 결과는 `Documents/CaptureResults/<UUID>/photo.jpg`, 설정/원본 SHA256을 포함한 `recipe.json`, 사용한 `look.cube`로 원자적으로 저장한다. 원본 bytes는 변경하지 않는다. 제공된 LUT의 크레딧/출처는 레시피 및 JPEG 캡션에 유지한다.
- 최근 촬영 화면은 효과 결과/원본을 구분해 공유할 수 있고, 사진 앱에는 원본과 성공한 결과를 함께 저장한다. 기존 사진 편집기는 별도로 유지한다.
- 현재 처리 한도는 기존 SDR 편집기와 같은 **12.6MP**다. HEIF 원본도 결과는 sRGB JPEG이며 원본 EXIF/HDR gain map은 결과로 복사하지 않는다. 한도 초과·깊이 누락·GPU/인코딩 오류는 원본을 보존하고 오류로 알린다. 실패 결과를 성공한 것으로 표시하지 않는다.

## 3. 별도 DEPTH 대신 PRO f값

- 촬영 모드 목록에서 `DEPTH`를 제거했다. **PRO → f/— → 심도 촬영**에서 켜고 `f/1.4~f/16`으로 강도를 조절한다. 사용 가능한 사진 깊이 입력이 없으면 비활성화/설명한다.
- 기존 AVFoundation 사진 세션을 그대로 쓴다. 현재 입력이 깊이를 전달하지 못하면 같은 방향의 LiDAR → 듀얼 와이드 → 듀얼 → 트리플 → TrueDepth 후보를 확인한다. 활성 입력/포맷에서 `isDepthDataDeliverySupported`를 다시 확인한 뒤 켠다. 특정 기기에서 LiDAR가 반드시 선택되거나 성공한다고 보장하지 않는다.
- 사진에 실제 깊이를 요청하고 HEIF/JPEG 원본에 내장한다. 심도 OFF 시 원래 렌즈로 복귀를 시도한다. 렌즈 변경은 기존 정책대로 AUTO 제어로 돌아갈 수 있으며, 지원 ISO/셔터/수동 초점 범위도 달라질 수 있다.
- 마지막 탭의 영상 좌표(초기 중앙)를 사용하며 전면 사진의 비미러링 좌표로 변환한다. 파일 EXIF 방향을 이미지와 깊이 데이터에 각각 한 번 적용한다.
- 유효한 주변 깊이의 중앙값을 기준으로 깊이 차이 마스크를 만들고 Core Image의 가변 Gaussian blur를 적용한다. 작은 f값은 강하게, 큰 f값은 약하게 적용한다. 유효하지 않은 깊이 픽셀에는 강제로 흐림을 만들지 않는다. 깊이 지도와 사진의 비율이 다르면 늘려 맞추지 않고 거부한다.
- **실제 렌즈 조리개 변경, 광학 보케/인물 사진의 완전한 재현이 아닌 소프트웨어 효과**다. 깊이 데이터가 없으면 인물 분할 등으로 가장하지 않는다. 상대 정확도의 깊이 값을 실측 미터로 주장하지 않고 레시피에 정확도를 구분한다.
- PRO 일반 단일 사진 전용이다. AUTO/RAW/브래킷/LONG/VIDEO로 전환하면 끈다. 심도 효과는 촬영 결과에 적용하며 실시간 흐림 프리뷰는 제공하지 않는다.
- 이전 ARKit 깊이 패키지 코드/포맷은 제거하지 않았지만 주 촬영 모드에서는 진입하지 않는다. 이번 결과는 Photos의 네이티브 portrait f값 편집 지원을 보장하지 않는다.

## 4. 장노출 시간 직접 입력·맨 앞 배치

- LONG 하단 조절 레일 맨 앞에 현재 시간(예: `4 s`, `12.5 s`)을 표시한다. ISO/셔터/EV/초점 및 AI 버튼보다 앞이다.
- 해당 항목의 패널 및 기존 장노출 창 맨 위에 숫자 입력과 빠른 선택을 제공한다. 1~300초, 소수와 쉼표 소수 구분자를 지원한다. 유효한 입력은 즉시 설정에 반영하고, 잘못된 입력은 마지막 유효 값을 유지한다.
- 이 값은 **다중 프레임 총 합성 시간**이다. 개별 센서 셔터 시간은 기존 “셔터”에서 지원 장치 범위 안에서 별도로 조절한다. 300초 센서 노출로 표시하지 않는다.
